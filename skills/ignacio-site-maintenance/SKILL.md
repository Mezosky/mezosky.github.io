# Ignacio Site Maintenance

## Overview

Use this skill for changes to Ignacio Meza's personal site and its supporting repo files. It keeps edits aligned with the current content, design direction, and workflow expectations for this repository.

## When To Use

Use this skill when the task involves any of the following:

- Editing the homepage, CV, publications, blog, news, or README
- Updating styles, animations, layouts, or site metadata
- Cleaning leftover template content or repo clutter
- Adjusting social links, profile presentation, or personal copy
- Finishing site work that should be committed and pushed

## Core Rules

1. Treat this repo as Ignacio Meza's personal site, not a generic `al-folio` template.
2. Keep the site professional, clean, and research-oriented.
3. Do not remove Ignacio's homepage photo unless the user explicitly asks.
4. Remove template leftovers when they are not relevant to Ignacio's site.
5. Keep animations subtle, intentional, and accessible.
6. Push completed work after verification unless the user says not to.

## Workflow

1. Read `references/repo-map.md` to find the right files quickly.
2. Read `references/design-and-content.md` when the task affects copy, layout, design, or tone.
3. Read `references/workflow.md` before finishing work so verification, commit, and push are handled consistently.
4. Prefer editing the current design system instead of reintroducing old theme defaults.
5. If the task touches public-facing content, check that the result still sounds like Ignacio and reflects his strengths in machine learning, computer vision, research, teaching, and good practices.

## References

  Read for file locations and which files control each part of the site.
- `references/design-and-content.md`
  Read for identity, design language, animation style, and good-practices expectations.
- `references/workflow.md`
  Read when verifying, committing, and pushing the finished work.
